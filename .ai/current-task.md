# Блок 5 — проверка результата и JSON-отчёт Python

**Статус:** реализован и проверен 07.09.2026. EPF и BSL не изменялись.

## Сделано

- Временный LGP проверяется по версии и GUID журнала-приёмника до атомарного `os.replace`.
- После публикации повторно проверяется заголовок и фиксируется размер файла.
- Для перенумерации сохраняется точное число обработанных записей.
- Опциональный `--report-json` добавляет SHA-256 каждого результата и сводку операции.
- JSON публикуется атомарно; ошибка сохранения отчёта не выдаётся за ошибку уже завершённого присоединения.
- В быстром побайтовом copy/merge записи повторно не разбираются и не подсчитываются.
- Добавлены тесты непубликации невалидного временного файла, расширения отчёта и фактического SHA-256.

## Производительность

Проверка заголовка на 100 МиБ: 10,480 с; 9,5 МиБ/с; peak RSS 28,5 МиБ. Измеримого ухудшения относительно предыдущего результата 10,916 с нет.

Результат сохранён в `benchmarks/verified-header-100mib.json`.
