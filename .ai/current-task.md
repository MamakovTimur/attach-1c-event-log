# Блоки 7–9 — устойчивое возобновление Python

**Статус:** реализован и проверен 07.09.2026. EPF и BSL не изменялись.

## Сделано

- Добавлен атомарный `.attach-event-log.operation.json` с `fsync` перед публикацией JSON.
- Контрольные точки фиксируют подготовку словаря, начало публикации и каждый подтверждённый LGP.
- Повторный запуск с теми же параметрами восстанавливает словарь, если ни один LGP не публиковался.
- Подтверждённый частичный результат продолжается без повторного объединения готовых периодов.
- Перед возобновлением сверяются SHA-256 исходного LGF, размеры и время изменения исходных LGP.
- Неоднозначное прерывание в фазе публикации блокирует новые записи и показывает путь к журналу.
- После полного успеха журнал и временная копия словаря удаляются.
- Добавлены сквозные тесты отката, продолжения без дублей и защитной блокировки.
