# Блок 2 — ускорение перенумерации Python

**Статус:** реализован и проверен 07.09.2026. EPF и BSL не изменялись.

## Основание

Профиль 10 МиБ показал, что 84% времени занимали удаление переносов, токенизация и обратная вставка переносов для каждой записи.

## Сделано

- Перенумерация заменяет только нужные числовые поля непосредственно в исходной записи.
- Пробелы, CRLF/LF, строки с запятыми и экранированные кавычки сохраняются без реконструкции записи.
- Добавлены прямые тесты реального Python-движка.
- Измеритель непрерывно читает прогресс процесса и не блокируется при больших объёмах.
- Генератор пишет данные блоками вместо миллионов мелких операций записи.

## Результат 100 МиБ

- До: 34,243 с; 2,9 МиБ/с; peak RSS 26,6 МиБ.
- После: 13,480 с; 7,4 МиБ/с; peak RSS 26,3 МиБ.
- Ускорение: 2,54 раза без роста памяти.

Результат сохранён в `benchmarks/optimized-direct-spans-100mib.json`.
