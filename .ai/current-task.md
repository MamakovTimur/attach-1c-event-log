# Блок 14 — компактные отпечатки серверной дедупликации

**Статус:** реализован в исходниках после релиза 1.3.39. EPF пока не пересобиралась.

## Сделано

- В серверном режиме длинная каноническая строка записи больше не остаётся ключом `Соответствие`.
- В памяти хранится SHA-256 в Base64 вместе с числом полей и суммарной длиной значений.
- Каноническая сериализация с префиксами длины сохранена и хешируется одним платформенным вызовом.
- Число полей и длина добавляют дешёвую проверку формы ключа поверх криптографического хеша.
- Клиентский режим сохраняет прежний строковый ключ: `ХешированиеДанных` недоступно тонкому клиенту.
- Добавлены статические контракты серверного хеша и клиентского fallback.

## Следующий маленький шаг

Добавить серверные метрики времени по фазам чтения, преобразования и публикации LGP, чтобы следующий блок выбирать по фактическому профилю.
