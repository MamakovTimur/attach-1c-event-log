# Блок 13 — потоковая разбивка LGP по дням

**Статус:** реализован в исходниках после релиза 1.3.39. EPF пока не пересобиралась.

## Сделано

- Разбивка по дням больше не открывает и не закрывает временный файл дважды на каждую запись.
- Одновременно открыт только один writer: при смене дня он строго закрывается, поэтому число файловых дескрипторов ограничено.
- Повторный переход к уже встречавшемуся дню корректно добавляет разделитель и не создаёт хвостовую запятую.
- UTF-8 BOM остаётся только в заголовке; тело дописывается без BOM одним буфером на запись.
- При любой ошибке reader/writer закрываются, а все созданные временные day-файлы удаляются.
- Добавлены контракты повторного использования writer, разделителей и строгого закрытия.
