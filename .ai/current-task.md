# Блок 11 — стабильный пакетный режим в чистой 1С

**Статус:** реализован в исходниках после релиза 1.3.39. EPF пока не пересобиралась.

## Сделано

- План пакетного присоединения фиксируется перед первым пакетом: файлы, пути, действия, каталоги, опции и контроль целостности.
- Изменение реквизитов формы во время ожидания между пакетами больше не смешивает старые карты с новым планом.
- При сохранении следующего состояния старый объект временного хранилища удаляется после успешной записи нового.
- При ошибке пакетной операции временное состояние очищается без потери исходной ошибки.
- Добавлены статические регрессионные проверки snapshot и порядка замены временного состояния.

## Следующий маленький шаг

Реализовать серверный кэш результата dry-run с инвалидизацией по пути, размеру и времени изменения LGF, чтобы перед присоединением не читать словари и не строить карты повторно.
