# Блок 3 — единый проход потокового парсера Python

**Статус:** реализован и проверен 07.09.2026. EPF и BSL не изменялись.

## Основание

После прямой замены полей профиль показывал два независимых посимвольных прохода: выделение записей из потока и повторное определение границ полей.

## Сделано

- Потоковый парсер возвращает текст записи вместе с уже найденными границами полей.
- Перенумерация использует эти границы без повторного сканирования.
- Старый интерфейс итератора сохранён совместимой обёрткой.
- Добавлены тесты разбиения на произвольных границах входных блоков, строк с запятыми и удвоенными кавычками.

## Результат 100 МиБ

- Релиз 1.3.38: 34,243 с; 2,9 МиБ/с; peak RSS 26,6 МиБ.
- Прямая замена полей: 13,480 с; 7,4 МиБ/с; peak RSS 26,3 МиБ.
- Единый проход: 10,916 с; 9,2 МиБ/с; peak RSS 25,5 МиБ.
- Итоговое ускорение относительно 1.3.38: 3,14 раза без роста памяти.

Результат сохранён в `benchmarks/optimized-fused-parser-100mib.json`.
