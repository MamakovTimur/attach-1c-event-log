# Присоединение журнала регистрации (старый формат)

Внешняя обработка для склейки ЖР текстового формата (`1Cv8.lgf` + `*.lgp`) после переноса ИБ в другой кластер.

- Платформа: 8.3.10+ (управляемая форма).
- Формат: не SQLite `.lgd`, а старый текстовый.
- Версия: **1.3.21** — качество merge (Фаза 2): опциональная дедупликация по fingerprint, разбивка источника по дням (с сохранением пар транзакций), предупреждения о незакрытых транзакциях и архивном lgf+lgp, golden-тесты.
- **1.3.20** — UX администратора (Фаза 1): мастер шагов, восстановление из `*.bak_`, расширенный поиск srvinfo (имя ИБ / дата / размер), экспорт протокола, ETA при перенумерации.
- **1.3.19** — сессионное состояние формы (кэш анализа, пакетное присоединение) через временное хранилище; реквизиты формы не могут быть Массив/Структура.
- **1.3.11** — сырое чтение/запись `.lgp` с сохранением LF внутри кавычек и CRLF между структурными строками (иначе «Ошибка формата потока»).
- **1.3.10** — у последней записи `.lgp`/`.lgf` нет хвостовой запятой; UUID типов 1/5 в lgf без кавычек (как у платформы). Иначе риск «Ошибка формата потока».
- **1.3.9** — индекс токенов словаря 0-based (`Токены[0]` = тип).
- **1.3.4** — в `.lgp` после GUID обязательна пустая строка; иначе «Ошибка формата потока».
- **1.3.3** — hotfix: перенумерация составного поля метаданных (цикл по массиву 0..ВГраница, не 1..Количество); индексы полей `.lgp` в коде — **0-based**.
- **1.3.2** — понятный протокол для админов; при простом копировании `.lgp` с чужим GUID переписывается заголовок на GUID/версию приёмника; незакрытая скобка на лимите выборки ~2 МБ не считается повреждением.
- **1.3.1** — hotfix: в модуле формы нельзя дублировать имена процедур/функций между `&НаКлиенте` и `&НаСервере` (форма не открывается). Режим «На сервере 1С» — через уникальные серверные методы `*НаСервереКонтекста`.
- Файловые хелперы: `&НаКлиентеНаСервереБезКонтекста`; оркестрация на сервере — только с **уникальными** именами.
- **Запрет:** не оставлять одно и то же имя у `&НаКлиенте` и `&НаСервере`. Проверка: `tests/check_duplicate_method_names.py`.
- Не использовать `ТекущаяДатаСеанса()` в клиентском UI — только `ТекущаяДата()`.
- Сборка EPF: временная файловая ИБ + Designer `/LoadExternalDataProcessorOrReportFromFiles`.
- **Релизы GitHub**: описание на русском, язык для админов (не кухня разработки).
- **Агент:** не конфигурация. Запрещены code-metadata и graph-metadata (индекс БП КОРП). Канон: `AGENTS.md`, `.cursor/skills/mcp-1c-epf`, `epf-bsl`. Субагенты: `1c-developer`, `1c-code-reviewer`, `1c-error-fixer`.
