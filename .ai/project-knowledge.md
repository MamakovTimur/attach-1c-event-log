# Присоединение журнала регистрации (старый формат)

Внешняя обработка для склейки ЖР текстового формата (`1Cv8.lgf` + `*.lgp`) после переноса ИБ или восстановления из копии в том же контуре.

- Платформа: 8.3.10+ (управляемая форма).
- Формат: не SQLite `.lgd`, а старый текстовый.
- Версия: **1.3.38** — устранение дефектов полного аудита: manifest V2 и безопасный restore, staging-публикация, потоковый UTF-8/UTF-16 merge, строгая дедупликация с кратностью, защита одинаковых каталогов, безопасный Python CLI и межконтекстный guard в CI.
- **1.3.37** — read-only dry-run; предупреждения dedup/split; zero-append без хвостовой запятой; единый `tests/run_all.py` + CI workflow.
- **1.3.33** — проверка заголовка .lgp бинарным префиксом 4 КБ; в dry-run не открываем файлы приёмника; явное предупреждение OneDrive/Desktop.
- **1.3.32** — hotfix: целостность без разбора тела (убран посимвольный `Сред` до 2 МБ).
- **1.3.30** — нейтральные подписи «Старый ЖР» / «Текущий ЖР»; прогноз времени.
- **1.3.29** — лёгкий dry-run; предупреждение сервер+Desktop/OneDrive/Users.
- **1.3.28** — тумблер «Режим выполнения».
- **1.3.27** — UX формы: блоки Каталоги / Резервная копия / Параметры склейки / Действия.
- **1.3.26** — вкладка «Справка».
- **1.3.25** — hotfix: `КаталогРезервнойКопии` параметром в безконтекстной обёртке.
- **1.3.24** — переключатель клиент/сервер, каталог резервной копии, вкладка «Справка».
- **1.3.23** — hotfix: форма не открывалась (`КонецПроцедуры` вместо `КонецФункции`).
- **1.3.21** — качество merge (Фаза 2): опциональная дедупликация, разбивка по дням (экспериментально с 1.3.37).
- Сборка EPF: временная файловая ИБ + Designer `/LoadExternalDataProcessorOrReportFromFiles`; 1.3.38 собрана и smoke-проверена на 8.3.27.2325.
- **Агент:** не конфигурация. Запрещены code-metadata и graph-metadata. Канон: `AGENTS.md`, skills `mcp-1c-epf`, `epf-bsl`. Субагенты: `1c-developer`, `1c-code-reviewer`, `1c-error-fixer`.
